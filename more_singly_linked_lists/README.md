# More singly linked lists

This project contains functions for manipulating singly linked lists of
integers.

## Files

- `lists.h` - Header file containing the `listint_t` structure and prototypes.
- `8-sum_listint.c` - Calculates the sum of all integers in a list.
- `9-insert_nodeint.c` - Inserts a node at a specified index.
- `10-delete_nodeint.c` - Deletes a node at a specified index.
- `100-reverse_listint.c` - Reverses a singly linked list.
- `101-print_listint_safe.c` - Safely prints a list, including lists with loops.
- `102-free_listint_safe.c` - Safely frees a list, including lists with loops.
- `103-find_loop.c` - Finds the beginning of a loop in a linked list.
